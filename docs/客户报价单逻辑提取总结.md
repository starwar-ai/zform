## 核心业务逻辑说明

### 1. 柜型数量自动计算

这是从 `zexport` 提取的最重要的业务逻辑之一。

#### 算法说明

```
输入: 外箱体积 × 箱数 = 总体积 (立方米)

计算步骤:
1. 优先填充 40尺高柜 (68 CBM)
2. 剩余体积填充 40尺柜 (58 CBM)
3. 再剩余体积填充 20尺柜 (28 CBM)
4. 最后剩余的为散货

输出: {
  container40hq: 数量,
  container40ft: 数量,
  container20ft: 数量,
  bulkCargo: 体积 (CBM)
}
```

#### 示例

**输入**:
- 外箱体积: 0.5 CBM
- 箱数: 200
- 总体积: 100 CBM

**计算过程**:
```
100 CBM ÷ 68 CBM = 1 个 40尺高柜 (剩余 32 CBM)
32 CBM ÷ 58 CBM = 0 个 40尺柜 (剩余 32 CBM)
32 CBM ÷ 28 CBM = 1 个 20尺柜 (剩余 4 CBM)
散货 = 4 CBM
```

**输出**:
```json
{
  "container40hq": 1,
  "container40ft": 0,
  "container20ft": 1,
  "bulkCargo": 4.00
}
```

### 2. 验证规则

创建或更新报价单时会自动验证:

1. **箱数验证**: 必须大于0
2. **外箱体积验证**: 必须大于0
3. **柜型数量一致性**: 用户输入的柜型数量必须与系统计算的一致

如果验证失败,会抛出相应的错误信息。

### 3. 状态流转

```
DRAFT (草稿)
  ↓ [提交审批]
PENDING_APPROVAL (待审批)
  ↓ [审批通过]              ↓ [审批拒绝]
APPROVED (已审批)       REJECTED (已拒绝)
  ↓ [客户接受]
ACCEPTED (已接受)
  ↓ [结案]
CLOSED (已结案)
```

### 4. 货币转换

导出报价单时支持货币转换:

```typescript
// 将报价单中的所有金额转换为USD
GET /api/quotations/:id/export?currency=USD

// 转换公式
convertedAmount = amount × (targetRate / sourceRate)
```

使用 `Decimal.js` 库保证精度计算。

## 技术实现亮点

### 1. 类型安全
使用 TypeScript 提供完整的类型定义,减少运行时错误。

### 2. 精确计算
使用 `Decimal.js` 库进行金融数值计算,避免浮点数精度问题。

### 3. 软删除
所有删除操作都是软删除(设置 `deletedAt` 字段),便于数据恢复和审计。

### 4. 事务处理
使用 Prisma 的关系创建功能,主表和明细表在同一事务中创建。

### 5. 业务逻辑封装
核心业务逻辑完全封装在 Service 层,Controller 层只负责请求/响应处理。

### 6. 错误处理
自定义 `QuotationError` 类,提供清晰的错误码和HTTP状态码。

### 7. 代码复用
货币转换、柜型计算等通用逻辑提取为独立方法。

## 使用示例

### 创建报价单

```bash
curl -X POST http://localhost:3001/api/quotations \
  -H "Content-Type: application/json" \
  -H "x-user-id: user-123" \
  -d '{
    "customerId": "cust-001",
    "customerCode": "C001",
    "customerName": "ABC Company",
    "currency": "USD",
    "validUntil": "2026-12-31T23:59:59Z",
    "items": [
      {
        "lineNumber": 1,
        "productCode": "P001",
        "unitPrice": 10.50,
        "boxCount": 100,
        "outerBoxVolume": 0.5,
        "container20ft": 1,
        "container40ft": 0,
        "container40hq": 1,
        "bulkCargo": 4
      }
    ],
    "submitFlag": true
  }'
```

### 查询报价单

```bash
# 获取详情
curl http://localhost:3001/api/quotations/{id}

# 分页查询
curl "http://localhost:3001/api/quotations?page=1&pageSize=20&status=APPROVED"

# 导出为USD
curl "http://localhost:3001/api/quotations/{id}/export?currency=USD"
```

### 审批流程

```bash
# 提交审批
curl -X POST http://localhost:3001/api/quotations/{id}/submit \
  -H "x-user-id: sales-001"

# 审批通过
curl -X POST http://localhost:3001/api/quotations/{id}/approve \
  -H "x-user-id: manager-001"

# 审批拒绝
curl -X POST http://localhost:3001/api/quotations/{id}/reject \
  -H "Content-Type: application/json" \
  -H "x-user-id: manager-001" \
  -d '{"reason": "价格过高"}'
```
