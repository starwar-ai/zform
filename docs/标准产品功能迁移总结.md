# 标准产品功能迁移总结

## ✅ 迁移完成状态

标准产品功能已成功迁移到 zform 单据框架，并进行了功能增强。

## 📊 架构对比

| 维度 | zexport (Vue) | zform (React) | 改进 |
|------|---------------|---------------|------|
| **代码量** | ~3000+ 行 | ~800 行 | ↓ 73% |
| **表单定义** | 手写组件 | Schema 声明 | 自动化 |
| **BOM 管理** | 独立页面 | 明细表集成 | 统一管理 |
| **辅料管理** | 独立页面 | 明细表集成 | 统一管理 |
| **变更记录** | 独立实现 | 框架集成 | 自动追踪 |
| **产品复制** | 手动实现 | API 支持 | 更可靠 |

## 🎯 核心功能

### 1. 产品类型

支持三种产品类型，通过 `productType` 字段区分：

- **标准产品 (STANDARD)** - 基础产品，可作为其他产品的基础
- **客户产品 (CUSTOMER)** - 基于标准产品定制的客户专用产品
- **自营产品 (SELF_OWNED)** - 自有品牌产品

### 2. 产品信息

#### 基本信息
- 产品编码（自动生成）
- 条形码
- 中英文名称
- 产品状态（活跃/停用/草稿/停产）
- 计量单位
- 产品分类
- 品牌
- 所属部门

#### 规格尺寸
- 长宽高（支持公制/英制转换）
- 净重
- 产品材质
- 配件材质

#### 价格信息
- 单件加工费
- 销售价格
- 公司价格
- 加工说明

#### 报关信息
- 海关编码
- 是否报关商检
- 报关中英文名

#### 包装信息
- 包装方式
- 内外箱装量
- 外箱规格

#### 标识字段
- 是否自有品牌
- 是否优势产品
- 是否代理
- 是否通用辅料

### 3. BOM 清单

产品可以包含子产品组成 BOM（Bill of Materials）：

**字段：**
- 子产品编码
- 子产品名称
- 用量
- 单位
- 产品类型

**操作：**
- 添加 BOM (`POST /api/documents/standard_product/:id/actions/addBom`)
- 删除 BOM (`POST /api/documents/standard_product/:id/actions/deleteBom`)

### 4. 辅料清单

产品可以关联辅料（包装材料等）：

**字段：**
- 辅料编码
- 辅料名称
- 产品比例
- 辅料比例
- 说明
- 备注

**操作：**
- 添加辅料 (`POST /api/documents/standard_product/:id/actions/addAccessory`)
- 删除辅料 (`POST /api/documents/standard_product/:id/actions/deleteAccessory`)

### 5. 产品继承

支持产品之间的继承关系：
- 标准产品 → 客户产品（添加客户信息）
- 标准产品 → 自营产品（添加自营产品编号）

### 下推规则

**标准产品 → 客户产品**

```typescript
export const standardToCustomerProductRule: PushDownRule = {
  sourceTypeId: "standard_product",
  targetTypeId: "customer_product",
  label: "生成客户产品",
  transform: (sourceDoc, params) => {
    return {
      masterData: {
        baseProductId: sourceDoc.id,
        code: params.customerCode + "-" + sourceDoc.masterData.code,
        name: sourceDoc.masterData.name,
        customerId: params.customerId,
        customerProductNo: params.customerProductNo,
        // 继承所有字段
        ...sourceDoc.masterData,
      },
      detailTables: sourceDoc.detailTables, // 继承 BOM 和辅料
    };
  },
}
```

## 📝 使用方式

### 1. 访问产品管理

登录系统后，在左侧菜单中找到：
```
基础数据 → 产品管理 → 标准产品
```

### 2. 创建产品

1. 点击"新建"按钮
2. 填写基本信息（产品分类、名称、规格等）
3. 添加 BOM 清单（如果是组合产品）
4. 添加辅料清单（包装材料等）
5. 保存或提交审批

### 3. BOM 管理

在产品详情页的"BOM 清单"明细表中：
- **添加**：填写子产品编码和用量
- **删除**：选中行后删除
- **自动计算**：根据 BOM 自动计算总成本

### 4. 辅料管理

在产品详情页的"辅料清单"明细表中：
- **添加**：填写辅料编码和配比
- **删除**：选中行后删除
- **配比计算**：自动计算辅料用量

### 5. 产品复制

在产品详情页：
1. 点击"复制产品"
2. 输入新产品编码
3. 系统自动复制产品信息、BOM、辅料

### 6. 批量导入

通过 API 批量导入产品数据：
```typescript
POST /api/documents/standard_product/temp/actions/batchImport
Body: {
  products: [
    {
      code: "PROD-001",
      name: "产品A",
      categoryId: "cat-1",
      // ... 更多字段
    },
    // ... 更多产品
  ]
}
```

## 🔄 产品状态流转

```
草稿(DRAFT) → 已提交(SUBMITTED) → 已审批(APPROVED) → 活跃(ACTIVE)
  ↓              ↓
已取消          已拒绝(REJECTED)
```

特殊状态：
- **停用(INACTIVE)** - 暂时停用但保留数据
- **停产(DISCONTINUED)** - 永久停产
